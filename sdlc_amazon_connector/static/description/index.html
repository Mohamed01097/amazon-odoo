How It Works

Integration in four steps. Done.

Connect Amazon Seller Central with Odoo through a clean setup flow designed for admins, operations teams, and marketplace managers.

Step 01

Add Amazon Instance

Configure marketplace, region, seller details, warehouse mapping, and Amazon SP-API credentials.

Step 02

Connect Seller Central

Authenticate with Login With Amazon and securely send signed SP-API requests using AWS Signature V4.

Step 03

Track Everything

Monitor dashboards, sync logs, product health, alerts, AI insights, and operational records from Odoo.

Step 04

Go Live

Trigger the first bulk import, schedule cron jobs, and your sync is fully automated.
